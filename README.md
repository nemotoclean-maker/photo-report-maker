# 写真報告書メーカー

写真と説明文からWord報告書を作るブラウザアプリです。描き込み、回転、並べ替え、顧客別ファイル名に対応します。

## API課金なしの説明文作成

1. Codexのチャットに写真フォルダーを指定し、「写真報告書メーカーに取り込む写真＋説明文ZIPを作って」と依頼します。
2. 返ってきたZIPをこのアプリへドラッグします。
3. 店名・施工日・報告者を入力し、説明文・場所名・掲載写真を確認してWord出力します。

写真を先にアプリへ入れた場合は「追加した写真をチャット用ZIPにする」で保存し、契約中のチャットにZIPを添付して説明文を依頼できます。返ってきた `captions.json` をアプリへドラッグします。説明文は画像のSHA-256で対応付けるため、並べ替えや同じファイル名による取り違えを防ぎます。

**AIが実行されるのはチャット側です。アプリだけで説明文を生成する機能ではありません。** AI/APIの通信・APIキー・中継サーバーはありません。チャット契約の利用上限は適用されます。チャットへの添付は利用者が行います。アプリの写真処理とWord生成はブラウザ内です。

除外・保留は削除せず別欄に残り、「報告書に掲載」で戻せます。拡大元の番号は並べ替え・掲載変更に追従します。拡大元を外した場合は、その写真単独の説明文を使います。手入力した内容は後から説明データを取り込んでも上書きしません。

## 説明文データ

ZIP直下に `captions.json`、その `filename` に記載された相対パスに画像を置きます。元画像や顧客データを公開リポジトリへ入れないでください。サンプルは合成画像のみをテストで使用します。

```json
{
  "format": "cleanlife-photo-report",
  "version": 1,
  "photos": [{
    "id": "photo-001",
    "filename": "photos/IMG_0001.jpg",
    "sha256": "画像ファイルのSHA-256（小文字16進数64文字）",
    "place": "厨房通路",
    "description": "床面に包装袋などのゴミが見られました。",
    "disposition": "include",
    "parentId": null,
    "reason": ""
  }]
}
```

- `disposition`：`include`（掲載）、`exclude`（除外）、`review`（保留）、`pending`（チャット依頼前）。
- 拡大写真は `parentId` に全景のIDを指定し、`description` に単独でも使える観察文を記載。自己参照・循環・複数段の対応は禁止。
- 判定・記述ルールは `caption-rules.txt`。衛生害虫駆除の報告書写真や施工記録を除外し、写真で分からない内容を補完しません。
- 1回100枚、画像1枚20MB、ZIP80MB、展開後合計160MBまで。JPEG・PNG・WebPに対応します。

## 検証・開発

追加の依存パッケージは不要です。既存のJSZipを使います。

```text
node --test tests/photo-import.test.cjs
python -m http.server 8768 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8768/` を開きます。SHA-256照合にはHTTPSまたはlocalhostを使ってください。

GitHub Pagesは従来どおりリポジトリ直下を配信します。必要な静的ファイルは `index.html`、`docxgen.js`、`jszip.min.js`、`ai-core.js`、`photo-package.js`、`photo-import.js` です。API利用料・追加サーバーは不要です。
